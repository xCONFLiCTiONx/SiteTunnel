Cloudflare WARP Setup on Windows

Official Guide

Follow these quick steps in the Cloudflare WARP desktop app on Windows to enable Local Proxy Mode:

  1. Open Cloudflare WARP: Click the Cloudflare cloud icon in the Windows taskbar system tray.
  2. Open Settings: Click the gear icon ⚙️ → select Preferences.
  3. Configure Proxy: Go to the Advanced tab → click Configure Proxy.
  4. Enable Local Proxy: Turn on the local proxy and set the listening port to 40000.
  5. Select Client Mode: Select Local Proxy mode in WARP's client mode list.
  6. Connect: Turn the main WARP toggle switch ON.
PowerShell / Command Prompt alternative: warp-cli mode proxy
warp-cli proxy port 40000
warp-cli connect

How It Works & Security Caveats

Architecture
  • Zero System Impact: Your games, Slack, and other Windows applications continue using your direct internet connection. Only the domains you specify in SiteTunnel pass through WARP.
  • Shared Browser Settings: Chrome shares proxy settings across all windows and profiles. SiteTunnel compiles your domains into a native Chromium PAC script.
  • Killswitch Protection: When set to Fail-Closed, if WARP drops offline, SiteTunnel drops requests to protected sites rather than leaking cleartext data to the open internet.
  • Ambient Toolbar Awareness: The toolbar icon badge always reflects your proxy state without interrupting you — amber ! when reconnecting, red ERR if down for 30s+, and red LEAK if unproxied.
  • Whole-Tab vs Domain: With Whole-Tab Tunneling active, opening a target site routes all third-party CDNs, external APIs, auth providers, and embedded subresources in that tab through WARP so nothing bypasses the proxy.
